# மழை முன்னறிவிப்பு நாட்காட்டி

`/prediction?year=2026&mode=aadi` மற்றும் `mode=margazhi` வழித்தடங்கள்
முறையே 180 மற்றும் 140 உள்ளூர் நாட்களை காட்டுகின்றன.

## காட்சிகள்

- `view=day` — ஒவ்வொரு நாளின் தேதி, தனிப்பயன் தமிழ் தேதி, ஆய்வு மதிப்பெண்,
  மழை வகை, கிடைக்கக்கூடிய நிகழ்தகவு, தரம், முறை மற்றும் நிலை.
- `view=week` — forecast day 1 முதல் தொடங்கும் ஏழு நாள் குழுக்கள்; கடைசி குழு
  குறைவான நாட்களைக் கொண்டிருக்கலாம்.
- `view=month` — Gregorian ஆண்டு/மாத அடிப்படையிலான குழுக்கள்.

வாரம் மற்றும் மாதம் காட்சிகள் probability-ஐ சராசரியாக்குவதில்லை. கிடைக்கும் தினசரி
probability மதிப்புகள் ஒரே மதிப்பாக இருந்தால் அதை, மாறினால் குறைந்த–அதிக வரம்பை
மட்டுமே காட்டும். மதிப்பு இல்லையெனில் `வெளியிடப்படவில்லை` எனக் காட்டும்.

## அறிவியல் பாதுகாப்பு

தற்போதைய `daily-timeline-1.0` மழை அளவு அல்லது calibrated probability உருவாக்காது.
எனவே probability மற்றும் category களங்கள் காட்சியிலும் CSV-யிலும் காலியாகவே இருக்கும்;
UI அவற்றை கற்பனை மதிப்பால் நிரப்பாது. `no_data` மற்றும் `experimental` நிலைகள்,
quality flag, prediction method, reason codes மற்றும் model/rule versions தெளிவாகத்
தக்கவைக்கப்படுகின்றன.

## CSV

`/prediction.csv?year=2026&mode=aadi` தினசரி பதிவுகளை UTF-8 CSV attachment ஆக
வழங்குகிறது. இதில் தேதி/தமிழ் தேதி, nullable research/probability/amount/category,
quality, method, reason codes, source-window boundaries மற்றும் அனைத்து version
புலங்களும் உள்ளன. ஏற்றுமதி திரையில் தேர்ந்தெடுத்த day/week/month grouping-ஐ அல்ல,
அசல் தினசரி timeline-ஐ எப்போதும் வழங்கும்.

## சிறிய திரைகள்

Desktop-இல் நாள் காட்சி அட்டவணையாக இருக்கும். 760px-க்கு குறைந்த திரைகளில் ஒவ்வொரு
நாள் row-வும் label கொண்ட தனி card ஆக மாறும்; வார/மாத grids ஒரு column ஆக மாறும்.
