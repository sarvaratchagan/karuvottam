# வானிலைத் தரவு ஆய்வுப் பக்கம்

`/observations` பக்கம் செயலில் உள்ள configured location-க்காகத் தரவுத்தளத்தில்
சேமிக்கப்பட்ட மணிநேர வானிலைப் பதிவுகளை ஆய்வு செய்கிறது.

## காலம் மற்றும் மூலம்

- `start` மற்றும் `end` query parameters உள்ளூர் `YYYY-MM-DD` தேதிகள்; இரண்டும்
  சேர்ந்து வழங்கப்பட வேண்டும்.
- அதிகபட்ச காட்சி வரம்பு 366 நாட்கள்.
- தேதி கொடுக்கப்படாவிட்டால் தேர்ந்தெடுக்கப்பட்ட சமீபத்திய source பதிவின் உள்ளூர்
  தேதியில் முடியும் ஏழு நாட்கள் காட்டப்படும்.
- `source` filter ஒரு provider/model source-ஐ தனியாக ஆய்வு செய்ய உதவும்; sources
  ஒன்றாகக் கலக்கப்படுவதில்லை.

## நேரத் தொடர்கள்

Server உருவாக்கும் dependency-free SVG காட்சிகள் கீழ்கண்ட normalized fields-ஐ
காட்டுகின்றன:

- வெப்பநிலை (`temperature_c`)
- ஈரப்பதம் (`relative_humidity_pct`)
- மேக மூட்டம் (`cloud_cover_pct`)
- மழை (`precipitation_mm`)
- காற்றின் வேகம் (`wind_speed_kmh`)

மூலப் புள்ளிகள் பச்சை நிறத்திலும் `is_interpolated` பதிவுகள் மஞ்சள்/ஆரஞ்சு
வட்டத்திலும் காட்டப்படுகின்றன. தொடர்ச்சியான ஒரு மணி நேரப் புள்ளிகள் மட்டுமே கோட்டால்
இணைக்கப்படும்; நேர இடைவெளியின் மீது கோடு வரையப்படாது. ஒரு field-இன் `NULL` மதிப்புகள்
அந்த chart-இல் தனியாக எண்ணப்படும்.

## விடுபட்ட மணிநேரங்கள்

உள்ளூர் தேதிகள் UTC query boundaries-ஆக மாற்றப்படுகின்றன. இந்தியாவின் `+05:30`
offset தவறான அரைமணி gaps உருவாக்காமல் இருக்க, coverage எதிர்பார்ப்பு stored hourly
UTC cadence-க்கு align செய்யப்படுகிறது. இல்லாத தொடர்ச்சியான மணிநேரங்கள் gap ranges ஆக
சுருக்கப்பட்டு தொடக்கம், முடிவு மற்றும் missing-hour count உடன் காட்டப்படுகின்றன.

## பாதுகாப்பான fallback

Configured location இல்லாதது, பதிவுகள் இல்லாதது மற்றும் migrate ஆகாத database ஆகியவை
500 பிழையாக மாறாது. தெளிவான தமிழ் எச்சரிக்கை, காலியான charts மற்றும் 0% coverage
காட்டப்படும். பதிவு அட்டவணை browser அளவை கட்டுப்படுத்த சமீபத்திய 100 பதிவுகளை மட்டும்
காட்டும்; summary மற்றும் charts தேர்ந்தெடுத்த முழு range-ஐ பயன்படுத்தும்.
