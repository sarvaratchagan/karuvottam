# கருவோட்டக் காலண்டர் காட்சி

`/calendar?year=2026` வழித்தடம் தேர்ந்தெடுத்த ஆண்டின் ஆடி மற்றும் மார்கழி
கருவோட்டச் சாளரங்களை விதி மற்றும் கணக்கீட்டு மூலத்துடன் காட்டுகிறது.

## ஒவ்வொரு சாளரத்திலும் காட்டப்படும் தகவல்

- தமிழ் மாதத் தொடக்க எல்லை.
- தேர்ந்தெடுக்கப்பட்ட அமாவாசை அல்லது பௌர்ணமி.
- சந்திர நிகழ்வின் `Asia/Kolkata` மற்றும் UTC நேரங்கள்.
- சேர்க்கப்படும் தொடக்கம் மற்றும் சேர்க்கப்படாத முடிவு `[start, end)`.
- 432 மணி ஆடி / 264 மணி மார்கழி கால அளவு.
- lunar provider, calculation version, calendar-rule version மற்றும் quality flag.
- அதே season/year/rule-version சாளரம் தரவுத்தளத்தில் உள்ளதா என்ற நிலை.

## மார்கழி alternation

தேர்ந்தெடுத்த ஆண்டை மையமாகக் கொண்ட ஐந்து ஆண்டுகளின் அமாவாசை/பௌர்ணமி
வரிசை காட்டப்படும். இயல்புநிலை reproducibility anchor `2026 = அமாவாசை`.
இந்த anchor-ஐ சூழல் அமைப்புகள் மாற்றினால் காட்சியும் அதே engine விதியிலிருந்து
மாற்றப்படும்; UI தனியாக phase-ஐ ஊகிப்பதில்லை.

## தரவுத்தள fallback

காலச் சாளரங்கள் deterministic விதி engine-இலிருந்து கணக்கிடப்படுகின்றன.
தரவுத்தளம் migrate ஆகவில்லை என்றாலும் பக்கம் கணக்கிடப்பட்ட காலங்களைக் காட்டும்;
persisted நிலையைச் சரிபார்க்க முடியவில்லை என்ற தெளிவான எச்சரிக்கையும் காட்டப்படும்.
